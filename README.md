# Diplom_3

Проект: Автоматизация UI тестирования для сервиса заказа межгалактических бургеров Stellarburgers.

Проект представляет собой автоматизированные тесты для веб-приложения,для оформления для сервиса заказа бургеров Stellarburgers. Тесты написаны на Java с использованием Selenium и JUnit.

## Описание проекта

Тесты написаны с использованием паттерна Page Object Model (POM).
Проект включает в себя автоматизированные тесты для проверки функциональности веб-приложения:

Регистрация пользователя:
- Успешнпя регистрацию.
- не успещная регистрация (Ошибка некорректной мин. длины пароля.)

Авторизация пользователя:
- Переход в личный кабинет:
- Переход из личного кабинета в конструктор
- Выход из аккаунта

Переход по разделам:

## Технологии

- Java 
- Selenium WebDriver
- JUnit 
- Maven 
- ChromeDriver 

## Основные тестовые классы
- SetUpTest - настройка предусловия запуска тестов
- MainPageTest — Тесты по авторизации пользователя
- RegisterPageTest — Тесты по регистрации пользователя
- SwitchSectionsTest — Тесты на переходы по разделам сайта


## Зависимости проекта:

Selenium Java 3.141.59
JUnit 4.13.2
maven 2.22.2
WebDriverManager 5.4.1

## Как запустить тесты

Убедитесь, что у вас установлены:

- Java (JDK 11 или выше)
- Maven
- Браузер Chrome или Яндекс

## Настройка окружения

Chrome:

Убедитесь, что установлен Chrome. Установите chromedriver той же версии что и Chrome

Яндекс:

Убедитесь, что установлен Яндекс. Установите chromedriver той же версии что и Яндекс браузер

## Запуск тестов
1. Запуск всех тестов
```zsh
mvn clean test
```
2. Генерация отчетов Allure
```zsh
mvn allure:serve
```
